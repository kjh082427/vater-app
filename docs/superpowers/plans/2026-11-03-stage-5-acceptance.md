# 5단계(배포) 확인 테스트 계획

> 사용자 요청: "각 단계 완료할 때마다 꼼꼼한 테스트 케이스 만들어서 테스트 진행까지 완료해줘." 통과하면 main에 `stage-5-release` 태그.

**Goal:** 스펙 0장 성공 기준 1(관리자 권한 없이 설치)과 5(자동 업데이트)를 실제 설치 파일과 실제 프로세스로 확인한다.

**Spec:** `docs/superpowers/specs/2026-11-02-vater-mvp-design.md` 0장, 8장(앱 업데이트 실패), 11장

## 손으로 확인할 것 (사용자, Windows)
- SmartScreen "추가 정보 → 실행"으로 설치
- 트레이 메뉴, Windows 알림과 클릭 이동, 첫 숨김 알림, 부팅 시 자동 실행
- 실제 한투 키로 마법사 10분 안에 완료
- 설정 > 일반 [업데이트 확인]과 [지금 설치]
