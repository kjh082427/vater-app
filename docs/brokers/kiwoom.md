# 키움증권: 보유 종목 연결 참고 노트

브랜치 `core/broker-kiwoom`에서 어댑터를 설계·구현할 때 보는 자료다. 표시: ✅ 공식 자료로 확인, 🔶 2차 자료, ❓ 미확인. **❓와 🔶는 구현 전에 공식 문서로 확인한다.**

## 사용자에게 받는 값
| 값 | 필수 | 비고 |
|---|---|---|
| 앱키, 시크릿키 | ✅ | 계좌별 발급 🔶 |
| 계좌번호 | ❓ | 호출에 필요한지, 토큰에 묶이는지 미확인. 화면 구분용 별칭은 어차피 받는다 |
| 사전 조건 | ✅ | 키움 계좌 보유, **HTS ID 연결** (공식). 앱 입력값은 아니다 |

## 인증
- 포털: https://openapi.kiwoom.com
- 토큰 `au10001`, 본문 `{"grant_type":"client_credentials","appkey":...,"secretkey":...}` 🔶
- 토큰 유효 기간 ❓

## 보유 조회
- `kt00018` 계좌평가잔고내역, 경로 `/api/dostk/acnt`, 헤더 `api-id: kt00018` 🔶
- 응답 필드와 연속 조회 방식 ❓
- 미국 주식도 지원(공식)하지만 잔고 API는 ❓

## 제한 (공식)
- 조회 TR: 국내 초당 5회, 미국 초당 5회(한국시간 9~10시는 3회)
- 계좌별(토큰별) 세션 1개: **다른 프로그램과 같은 키를 함께 쓰면 끊길 수 있는지 확인 필요**
- 3개월 미접속 시 매월 첫 영업일에 자동 해지. 해지되면 연결 오류와 재신청 안내를 보여야 한다

## 주문 금지
- 기존 가드는 한투 패턴만 막는다. 키움 주문 TR과 경로를 가드에 더한다(공식 문서로 목록 확인).
- 호출 가능한 `api-id`를 허용 목록으로 고정한다.

## 확인할 것
- [ ] 계좌번호 입력 필요 여부, 한 키로 여러 계좌 조회 가능 여부
- [ ] `kt00018` 응답의 종목코드 형식(접두어 유무), 수량 필드
- [ ] 미국 잔고 API
- [ ] 세션 1개 제한이 REST 조회에도 적용되는지
- [ ] 약관상 사용자 본인 키를 넣는 배포 앱 허용 여부
