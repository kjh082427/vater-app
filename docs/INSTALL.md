# Vater 설치 안내

Vater는 Windows 10/11용 설치형 앱입니다. 관리자 권한 없이 설치되고, 설치한 뒤에는 인터넷 연결만으로 계속 쓸 수 있습니다.

> 투자 판단 보조용이며 투자 권유가 아닙니다. 앱에는 주문 기능이 없습니다.

## 1. 내려받기
[Vater 릴리스 페이지](https://github.com/kjh082427/vater-releases/releases/latest)에서 `Vater_<버전>_x64-setup.exe`를 받습니다.

## 2. 설치
1. 받은 파일을 실행합니다.
2. **"Windows의 PC 보호" 파란 창이 뜨면** [추가 정보]를 누르고 [실행]을 누릅니다. 1차 버전은 유료 코드 서명을 하지 않아서 처음 설치할 때 이 경고가 뜹니다. 앱 업데이트 파일은 별도의 서명으로 검증합니다.
3. 설치에 관리자 권한은 필요 없습니다. `%LOCALAPPDATA%\Vater`에 설치됩니다. WebView2가 없는 PC에서는 설치 중에 자동으로 받습니다.

## 3. 첫 실행 마법사
처음 실행하면 마법사가 열립니다. 10분 안에 끝낼 수 있습니다.

1. **환영·면책**을 읽습니다.
2. **한국투자증권 연결**: 앱키, 앱시크릿, HTS ID를 넣고 실전/모의를 고른 뒤 연결을 시험합니다.
   - 키는 [한국투자증권 KIS Developers](https://apiportal.koreainvestment.com/)에서 신청합니다.
   - 키는 Windows 자격 증명 관리자에 저장되고, 저장한 뒤에는 화면에 다시 보이지 않습니다.
3. **AI 엔진**: 클라우드 키 입력, 로컬 설치(Ollama), 나중에 중 하나를 고릅니다.
4. **감시 종목 추가**(선택)
5. **완료**: 부팅 시 자동 실행 여부를 고릅니다(기본 켬).

## 4. 쓰는 방법
- **창을 닫아도 트레이에서 알림 감시가 계속됩니다.** 완전히 끄려면 트레이 아이콘 메뉴의 [종료]를 누릅니다.
- **홈 화면 구성**: 홈의 [배치 편집]에서 칸 수, 배치, 칸마다 띄울 내용을 고릅니다. 위쪽 탭으로 화면을 여러 장 만들 수 있습니다.

## 5. 업데이트
- 앱을 시작하면 새 버전을 조용히 확인합니다. 새 버전이 있으면 알림과 배너가 뜨고, 눌러서 **설정 > 일반 > [지금 설치]**로 설치합니다. 설치하면 앱이 다시 시작됩니다.
- 언제든 **설정 > 일반 > [업데이트 확인]**으로 직접 확인할 수 있습니다.
- 업데이트 파일은 서명을 확인한 뒤에만 설치합니다. 확인에 실패하면 현재 버전을 그대로 쓰고 다음 실행 때 다시 확인합니다.

## 6. 제거
Windows 설정 > 앱 > 설치된 앱에서 **Vater**를 제거합니다. 설정과 기록은 `%APPDATA%\Vater`에 남습니다. 함께 지우려면 이 폴더를 직접 삭제합니다.

## 문제가 생기면
- **"백그라운드 서비스를 실행하지 못했습니다"**: 화면의 [로그 폴더 열기]로 `%APPDATA%\Vater\logs`를 엽니다. 백신이 `vater-core.exe`를 막지 않았는지도 확인합니다.
- **"한국투자증권 키를 확인하세요"**: 키가 틀렸거나 만료되었습니다. [설정 열기]에서 키를 다시 저장합니다.
